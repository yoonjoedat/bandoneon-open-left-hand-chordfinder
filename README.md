# bandoneon-open-left-hand-chordfinder
The 5th is omitted for 7, maj7, m7, m6, 6 and m(maj7); aug includes the ♯5. m7♭5, dim7, 7♭9 and m9 are shown as three-note voicings without the root. The recommended root is the lowest available button (C2 excluded). Press “Save” to keep it for next time. A note appears if you change the voicing so the root is no longer the lowest.
